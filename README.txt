INOGPT — VERSIÓN CORREGIDA

1. Abre .env y coloca tu clave real:
   OPENAI_API_KEY=TU_CLAVE_REAL

2. Ejecuta INICIAR_INOGPT.bat.

3. Si algo falla, ahora inoGPT mostrará el motivo exacto: clave rechazada, límite/facturación, configuración del modelo o problema del servidor.

4. Puedes abrir http://localhost:3000/api/health para comprobar si el servidor detecta la clave. Nunca muestra la clave.

El modelo predeterminado es gpt-6-luna.
Nunca compartas el archivo .env ni tu clave API.


NUEVO: MODO IMAGEN
Pulsa el boton 🖼️ junto al cuadro de texto, escribe lo que quieres ver y envia. La imagen se genera usando la API de OpenAI.

Las respuestas del chat tambien muestran formato, listas, negritas y emojis/iconos cuando ayudan a entender mejor.
